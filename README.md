# Student Result Analysis using Excel

## Project Overview

This project analyzes the academic performance of 20 CSE students using Microsoft Excel.

## Objectives

- Calculate total marks
- Calculate average marks
- Calculate percentages
- Assign grades
- Identify pass and fail students
- Analyze subject-wise performance
- Create data visualizations

## Tools Used

- Microsoft Excel
- Excel Formulas
- Conditional Formatting
- Charts

## Excel Functions Used

- SUM
- AVERAGE
- IF
- MIN
- MAX
- COUNTIF

## Project Sheets

### Student Data
Contains student marks and calculated results.

### Summary
Contains overall performance, subject-wise analysis and grade distribution.

### README
Contains project documentation.

## Project Outcome

The project provides a clear view of student academic performance through calculations, analysis and visualizations.
